# Regine Portfolio Website

Interactive constellation-style engineering portfolio for Regine Yap.

## Direction
The site presents software engineering, AI, DevOps, cloud and platform engineering as connected parts of one technical profile rather than isolated skill lists.

## Run locally
Open `index.html` directly, or serve the directory with any static HTTP server.

## Current iteration
- Responsive constellation landing experience
- Interactive engineering skill graph
- Selected project case-study summaries
- Experience timeline
- Lightweight canvas star field with no framework dependency

Built as a static site so it can be deployed easily to GitHub Pages or any static host.
